# License matrix

| component | license |
|---|---|
| code in this repository | Apache License 2.0 (`LICENSE`) |
| SonoIntent-authored questions and reference reasoning | CC BY 4.0, to be released with the annotation package |
| 30 source datasets, their masks and derived frames | each source's own terms; SonoIntent does not relicense them |

The annotation package's per-source register records the license, DOI and
access restrictions for each source, with `unverified` where no evidence
exists.

## Known per-source facts

- **CAMUS:** CC BY-NC-SA 4.0 — non-commercial and share-alike obligations
  apply.
- **PSFHS, HC18:** CC BY 4.0.
- **BUSI:** CC BY 4.0 per the mirror card.
- **CUBS, STMUS:** open access with citation requirements.
- **BUS-BRA:** MIT-style local license with a citation obligation.
- **EchoNet-Dynamic:** redistribution prohibited.

Other sources have no verified data-level license. Users must check each
source's terms before use or redistribution.
